Hostname:
Check the current hostname: hostnamectl or hostname
Change the static hostname: sudo hostnamectl set-hostname your-new-hostname
sudo hostnamectl set-hostname "Your Production Server" --pretty (spaces)


Swap Configuration: (Swap=32 GB)
sudo dd if=/dev/zero of=/swapfile bs=1G count=32
sudo chmod 600 /swapfile
sudo mkswap /swapfile
sudo swapon /swapfile
sudo swapon -s
sudo vi /etc/fstab
sudo /swapfile swap swap defaults 0 0

INSERT (to start typing)

| Key | What it does                        |
| --- | ----------------------------------- |
| `i` | Insert **before** cursor            |
| `a` | Insert **after** cursor             |
| `o` | Open **new line below** (MOST USED) |
| `O` | Open **new line above**             |


Save and exit
Press Esc (exit insert mode)
type: :wq
Press Enter

If you want to exit without saving: :q!

| Action            | Command       |
| ----------------- | ------------- |
| Insert mode       | `i`, `a`, `o` |
| Exit insert mode  | `Esc`         |
| Save              | `:w`          |
| Save & exit       | `:wq`         |
| Quit without save | `:q!`         |
